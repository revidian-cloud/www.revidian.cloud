# The Revidian Cloud marketing website ([www.Revidian.Cloud](https://www.Revidian.Cloud))

This is the public repository for the Revidian Cloud marketing website, a static website generated by [Hugo](https://GoHugo.io).


## Run Locally

You can run this website locally by cloning this repo and serving it with Hugo:

```
git clone --recurse-submodules https://github.com/revidian-cloud/www.revidian.cloud.git
cd www.revidian.cloud
hugo -s src serve
```
